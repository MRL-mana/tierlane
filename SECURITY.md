# Security policy

## Supported versions

Security fixes are applied to the latest release and the current `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or leaked secret.

Use GitHub's private vulnerability reporting feature on this repository's **Security** tab. Include the affected version, a minimal reproduction, expected impact, and suggested mitigation when available.

Never attach real API keys, tokens, private prompts, customer data, or personal filesystem contents. Replace sensitive values with clearly marked placeholders.
