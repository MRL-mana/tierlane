# Changelog

## 0.3.0 - 2026-08-30

- Add `tierlane doctor` to inspect config, local/cloud labels, and CLI availability without calling any backend.
- Add JSON doctor output for scripts and CI checks.

## 0.2.0 - 2026-08-30

- Add `tierlane init` to create a valid starter configuration after installation.
- Refuse to overwrite an existing configuration.
- Add Japanese documentation, social preview assets, contribution guidance, security reporting, and issue forms.
- Test Python 3.11, 3.12, and 3.13 in GitHub Actions.

## 0.1.0 - 2026-08-30

- Initial public release with cost-aware routing, escalation, secret scanning, cloud-egress consent, read-root sandboxing, and recursion protection.
